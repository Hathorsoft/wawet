# Wawet Relay — coverage role under investigation

Low-cost fixed installation at homes, farms, rooftops or temporary sites,
potentially USB/mains or solar powered. Distinguish a radio modem from a
Reticulum transport node: RNode hardware alone is not assumed to perform
routing or store-and-forward. Compare the cheapest proven compatible forwarding
implementation with a small Linux host before selecting either.

Experiments must measure forwarding capability, legal airtime, queue starvation,
continuous/solar power, siting/antenna/weather protection and expiry. An LXMF
propagation node is a distinct role, not automatic road-event retention.
No Relay firmware or board exists yet; do not buy an SBC without measuring the
actual workload, and do not promise an autonomous MCU relay without evidence.
