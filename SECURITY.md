# Security policy

Wawet 0.1 is experimental. There are no supported production firmware or hardware
releases. The repository must not be relied upon for emergency response or safe
driving decisions. See [threat model](docs/security/threat-model.md).

For a sensitive vulnerability, use GitHub's private vulnerability reporting if
it is enabled for this repository. Otherwise contact a maintainer privately
through their published profile contact details; do not post secrets, personal
location data or active exploit details in a public issue. This repository does
not yet configure a reporting mailbox or guarantee that GitHub private reporting
is enabled. Establish a monitored private channel before any public pilot.

Provide affected revision, reproduction, impact and a minimal synthetic example.
Maintainers should acknowledge, reproduce, coordinate a fix and publish a
bounded advisory when appropriate. No response-time SLA or bounty is promised.
For ordinary non-sensitive bugs use the bug template. Dependency advisories and
upstream firmware issues may require coordination with their maintainers; do
not assume Wawet owns their release process.
