# Wawet

Wawet is an early-stage communications ecosystem maintained by Hathorsoft Ltd.
Its initial application is collaborative road reporting, with Wawet Drive as the
first product direction. Reticulum is the proposed common networking layer.

The original car-network discussion dates to 25 February 2025 at 13:25:57 GMT.
LoRa/ESP32 implementation exploration began on 7 April 2025 at 12:26:25 BST.
