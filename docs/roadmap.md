# Staged roadmap

No promised dates. Move on only when exit evidence supports the next investment.

| Phase | Work | Exit gate |
| --- | --- | --- |
| 0 — Foundation | Monorepo, simulator, experimental protocol, research, licences and review | Runnable demo/checks, documented limits and prioritised feasibility experiments; this iteration |
| 1 — Network/radio proof | Resolve RNS licence scope, two compatible regional radio units, authenticated RNS, contact/airtime tests, BLE bench proof | Reproducible fresh event delivery and understood host/regulatory requirements |
| 2 — Drive prototype | GNSS decision, buttons, USB/vehicle power, supplied antenna, BLE | Standalone basic operation, valid location/time and safe stationary UX tests; controlled vehicle experiments only with test plan |
| 3 — Custom electronics | PCB, RF layout, enclosure, modular mounts, thermal/vibration, manufacturing test pads | Prototype passes electrical/RF/environmental tests with costed BOM |
| 4 — Network pilot | Multiple vehicles, Relay/Gateway, opt-in mobile prototype, privacy/abuse tests | Participant consent, authenticated reports, useful coverage/freshness and measured support needs |
| 5 — Productisation | DFM, conformity/certification, supply chain, QA, packaging/onboarding, recovery/updates | Documented compliant manufacturable product, viable economics and support/warranty model; small batch |
| 6 — Ecosystem expansion | Pocket, HaLow backhaul, home integrations, justified fleet features and optional long-distance research | Each application passes its own privacy, power, regulatory and usefulness gates |

Public road trials do not precede radio/driver safety review. A failed standalone
cost or encounter-delivery experiment may require changing the architecture or
first product rather than forcing the roadmap forward. Sensor is future scope;
no prototype is promised in the foundation.
