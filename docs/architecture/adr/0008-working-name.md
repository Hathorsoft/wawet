# 0008 — Wawet working name

Status: Accepted working name; clearance pending
Date: 4 October 2026

## Context

Wawet is inspired by Wepwawet; it is not a literal translation. Hathorsoft Ltd is the owner/principal maintainer and intended official manufacturer.

## Decision

Use Wawet for ecosystem/product naming with provisional tagline. Keep wire identifiers numeric/versioned and independent of branding.

## Alternatives

Attaching Hathorsoft to each product name confuses project and manufacturer. Treating the name as legally cleared would be unsupported.

## Consequences

Compatible third-party products need no false endorsement. A future rename should not change packet semantics.

## Revisit gate

Formal trademark clearance and policy review before commercial launch.
