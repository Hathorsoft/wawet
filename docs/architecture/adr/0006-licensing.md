# 0006 — Open-source licensing scope

Status: Accepted
Date: 4 October 2026

## Context

Owner chose open designs with commercial derivatives and protected branding. Current RNS/LXMF are not plain MIT.

## Decision

Apache-2.0 original software/specs, CC BY 4.0 prose, CERN-OHL-S v2 future original design source; preserve all upstream obligations.

## Alternatives

GPL/LGPL/MPL still allow sales; source-available exclusive-sales restrictions conflict with genuine open source. CERN P/W/S offer different hardware reciprocity.

## Consequences

No exclusive Hathorsoft sales right. Upstream restricted dependencies are optional and separately labelled; commercial bundle requires exact-version review.

## Revisit gate

Before hardware/RNS distribution verify notices, reciprocal source and use restrictions. See ../../../LICENSING.md.
